# Forest photographs

The site uses these files automatically. Until a file is here, that scene
shows the drawn landscape instead.

| File | Where it appears | What works best |
|---|---|---|
| `forest-hero.jpg` | Homepage hero | Misty forest or sunlight through tall trees, landscape, bright upper-right area for the sun rays |
| `forest-lake.jpg` | Homepage quote band and admin login | Forest lake or river at sunset / dusk |
| `forest-canopy.jpg` | Register and Verify page banners | Wide forest or canopy view |

Use JPEGs about 2400 px wide, under ~500 KB each. Make sure you have the right
to use each photo (for example the Unsplash or Pexels licence, or your own
campaign photos).
